# 🚀 Coddy – JavaScript Coding Challenges

## 📖 Projektbeschreibung

Dieses Repository dokumentiert meinen Lernfortschritt auf **Coddy**.
Hier sammle ich verschiedene JavaScript-Challenges, Algorithmen, Übungen und Problemlösungen, die ich während meines Lernwegs bearbeite.

Der Fokus liegt auf dem Verständnis grundlegender und fortgeschrittener Programmierkonzepte sowie auf der kontinuierlichen Verbesserung von Logik, Problemlösung und sauberem Code.
